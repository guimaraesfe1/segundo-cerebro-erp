# Meu Segundo Cérebro com IA — ERP

## Tema
Utilização de sistemas ERP na gestão empresarial.

## Objetivo
Criar um assistente inteligente especializado em sistemas ERP, capaz de explicar funcionalidades, módulos e processos empresariais, utilizando fontes confiáveis.

## Fontes utilizadas
- Odoo: https://www.odoo.com/documentation/
- SAP: https://www.sap.com/brazil/products/erp.html
- TOTVS: https://www.totvs.com/
- Canal oficial Odoo: https://www.youtube.com/@Odoo

## Diretriz do especialista
O notebook foi configurado para atuar como um especialista em ERP, explicando os módulos de estoque, vendas, PDV, compras e financeiro, utilizando as fontes adicionadas como referência.

## Perguntas realizadas
1. O que é um ERP e como ele integra os diferentes setores?
2. Como funciona uma venda em um ERP?
3. Como funciona o controle de estoque?

As respostas foram verificadas por meio das citações apresentadas pelo NotebookLM.

- Apresentação sobre os módulos de um ERP.
