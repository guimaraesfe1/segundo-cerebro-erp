# Materiais Gerados

Esta pasta armazena os materiais produzidos pelo Google NotebookLM a partir das fontes do segundo cérebro sobre ERP.

## Tipos de materiais

| Material | Formato | Pasta | Status |
|----------|---------|-------|:------:|
| Mapa mental | PNG | [`mapa-mental/`](mapa-mental/) | ⬜ Pendente |
| Apresentação de slides | PDF | [`apresentacao/`](apresentacao/) | ⬜ Pendente |
| Guias de estudo | PDF ou Markdown | `materiais/` (raiz) | ⬜ Pendente |
| Resumos | PDF ou Markdown | `materiais/` (raiz) | ⬜ Pendente |

## Convenção de nomes

Utilize nomes descritivos, em letras minúsculas e sem espaços:

| Exemplo | Conteúdo |
|---------|----------|
| `mapa-mental/mapa-mental-erp.png` | Mapa mental exportado do NotebookLM |
| `apresentacao/apresentacao-modulos-erp.pdf` | Apresentação sobre os módulos de um ERP |
| `guia-de-estudo-erp.md` | Guia de estudo gerado pelo NotebookLM |
| `resumo-erp.md` | Resumo gerado pelo NotebookLM |

## Orientações

- Salve somente materiais **efetivamente gerados** pelo NotebookLM.
- Após adicionar um material, atualize o status nesta página e na seção **Materiais gerados** do [README principal](../README.md).
- Registre, se possível, uma captura de tela do material dentro do NotebookLM em [`../evidencias/`](../evidencias/).
